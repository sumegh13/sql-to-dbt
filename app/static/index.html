Migrate stored procedures to dbt

Bring your T-SQL procedures and table definitions. Each one is translated to a dbt model, run next to the original on the same data, and only marked verified when every row matches.

Drop a folder or a .zip here

Any layout works: SSMS "Generate Scripts" output, one procedure per file, or mixed scripts. Include the CREATE TABLE scripts for the tables your procedures use. INSERT scripts are used as test data when present.

A fine-grained token with read-only "Contents" access to that repo is enough.

Read-only: reads procedure and table definitions and samples rows. Nothing is written to your database. Use a read-only login. The server must be reachable from where this app runs.

Required. Your key is used only for this job and is never saved or logged. A 50-procedure run costs about $0.05 with Claude Haiku, billed to your Anthropic account.
